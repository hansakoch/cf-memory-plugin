CF Memory Plugin

Persistent agent memory via Cloudflare Agent Memory. You call HTTP. Cloudflare stores and recalls.

GitHub · Agent card · Beta waitlist · Pricing

Install

pip install git+https://github.com/hansakoch/cf-memory-plugin.git
export MCP_CLOUDFLARE_API_KEY="scoped-token"
export CF_ACCOUNT_ID="your-account-id"
cf-memory test

No default account. Token needs Agent Memory permission. Paid Workers required to apply; paid ≠ access.
